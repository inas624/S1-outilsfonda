# S1 – Outils fondamentaux

Ce dépôt rassemble les travaux pratiques du module et un projet personnel réalisé en Python.

## Organisation

- `tp/` : les six dossiers de TP, avec les exercices d'origine, les fonctions communes et un README explicatif dans chaque dossier.
- `projet/` : projet personnel de comparaison de pizzas par surface et par prix.

## Projet personnel

Le projet étudie une question simple : une grande pizza est-elle forcément plus avantageuse ? Le programme calcule les surfaces, le prix au cm² et compare l'effet d'une augmentation du diamètre. Il utilise la géométrie du disque et les nombres flottants.

Pour le lancer, ouvrir `projet/main.py` dans PyCharm et cliquer sur **Run**. Les résultats sont affichés et enregistrés dans `projet/results.txt`.

## Environnement

Python 3.10 ou plus récent est conseillé. Le projet personnel utilise uniquement la bibliothèque standard. Pour les TP, installer les bibliothèques avec `python -m pip install -r requirements.txt` (NumPy pour le TP4 et Matplotlib pour produire le dessin du TP6).

Le dossier `.venv` et les fichiers de configuration propres à PyCharm ne sont pas inclus dans le dépôt ; ils doivent être recréés sur chaque ordinateur.

Une assistance par intelligence artificielle a été utilisée pour aider à la rédaction du code, à la correction de certaines erreurs et à la préparation de la documentation. Les résultats et le fonctionnement du programme seront vérifiés avant le rendu final.
