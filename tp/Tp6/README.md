# TP6

Ce dossier rassemble les fichiers d'exercices du TP6.

## Notions travaillées

Vecteurs, distances, déterminants, polygones, intersections, tests d'appartenance et estimation d'aire.

## Organisation

- Les fichiers numérotés (`1.1.py`, `1.2.py`, etc.) correspondent aux exercices.
- `support.py` rassemble les imports et les fonctions communes nécessaires à certains exercices qui réutilisent des notions ou fonctions précédentes.

## Exécution

Ouvrir le dossier `Tp6` dans PyCharm. Les fichiers `.py` peuvent être lancés séparément avec leur bouton **Run** ; `support.py` fournit les imports, fonctions et données communes utilisés par plusieurs exercices. Le dossier doit rester complet pour que les imports depuis `support.py` fonctionnent.

Certaines mesures de temps peuvent varier selon l'ordinateur. Pour les exercices qui utilisent NumPy (TP4), installer la dépendance avec `python -m pip install numpy`.
